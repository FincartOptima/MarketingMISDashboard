BD Performance — Accountability Tracker

This tab reads two sheets from the same BD Accountability Tracker upload. The call funnel below comes from the BD Daily Log sheet (per rep, per day) plus the tracker's own GMeet Joined? column. The lead-level sections further down come from the "<Person> Q<N>" sheets, matched to B2C by email for Stage/RM/Team/Platform. Month + Person apply to everything; Team + Platform only apply to the lead-level sections, since the Daily Log has no per-lead linkage to derive them from.

Call Flow — Calls to Meetings Joined

Call Flow — Stage by Stage

Each stage as a share of the stage it came from — e.g. Meeting Joined ÷ Meetings Scheduled. Meetings Scheduled and everything below it come from the tracker sheets (Date Assigned / GMeet Joined?): Joined + Not Joined + Pending + Not Logged always add up to Meetings Scheduled exactly ("Not Logged" = no GMeet Joined? value entered yet). Only Calls Connected → Meetings Scheduled crosses from the Daily Log into the tracker, so treat that one percentage as directional. See the Source column for exactly where each row comes from.

Calls by Month — Made vs Connected vs CNP

Three bars side by side per month, counts printed above each. Honors the Month/Person filters above — Team/Platform don't apply to this sheet.

Call Activity by BD Rep

Total Calls Made / Calls Connected / CNP as entered in the BD Daily Log sheet (not recomputed from each other) — a handful of rows in the source don't add up exactly; see the chart's info button for details. Connected % and CNP % are ÷ Total Calls Made. Meetings Scheduled is tracker-sourced, not from this sheet — see the Call Flow section above. Click any column header to sort.

RM Master Mapping — Source Name → Correct RM → Team

Maps abbreviated or variant RM names from FY 2026-2027, Plan Approval, and Revenue Input to the canonical RM name + team. Whenever a source file uses a non-standard name (e.g. "Vivek" instead of "Vivek Singhal"), add a row here. Edits persist in your browser and update all tabs immediately. Download to Excel for bulk edits, re-upload to replace. Export snapshot.js commits changes to the bundled snapshot. Calculate recomputes every tab on the dashboard.
